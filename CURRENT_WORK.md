## Admin route lockdown (2026-11-06, uncommitted — backend needs rebuild + restart to take effect)
- **Problem**: 144 write-method routes had no active guard (no class-level or global guard exists). Exception: `admin/signup` got its original full set (super_admin + create permission). Also locked private lists with no public caller: contact, newsletter, manuscript, coupon, gallery-by-admin, file-folder-by-admin `get-all`.
